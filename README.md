# fontctl

Minimal font manager for Linux written in POSIX compliant shell script.

## Why?

As we all know, managing fonts can get quite complex very quickly, because on Linux we have a few standard directories to place fonts in and that's that.
This simple, POSIX compliant, utility/script aims to solve this by using symlinks and neatly organizing your fonts. It allows you to enable/disable fonts
very easily.
